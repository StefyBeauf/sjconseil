# sjconseil

Site vitrine premium de SJ Conseil.

Homepage statique en one-page, compatible GitHub Pages, avec une direction artistique ivoire champagne éditorial.

## Structure

- `index.html` : homepage complète
- `styles.css` : direction artistique, responsive et mise en page
- `script.js` : menu mobile, ancres, effets discrets et expertises interactives
- `assets/` : logo, visuel hero, photo et logos partenaires
- `CNAME` : domaine personnalisé `www.sjconseil.fr`

## Test local simple

Ouvrir `index.html` dans un navigateur suffit.

Pour tester comme un vrai site local :

```bash
python3 -m http.server 8080
